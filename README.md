Quiz Questionnaire Project
Overview
This project is a Python-based quiz application that demonstrates:
- Object-Oriented Programming (OOP) concepts
- Working with JSON data
- Building interactive questionnaires in the terminal
The program loads quiz questions from JSON files, presents them to the user one by one, accepts user input, and calculates the final score


Features
- Question class: Represents a single quiz question with its text, choices, and correct answer.
- Questionnaire class: Manages a collection of questions and runs the quiz.
- Interactive gameplay: Users answer questions by typing the number corresponding to their choice.
- Validation: Ensures the user enters a valid numeric response.
- Scoring: Displays the total score at the end of the quiz.
- JSON integration: Questions can be loaded dynamically from JSON files generated from external quiz databases.
